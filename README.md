# Task Manager with CI/CD and GitHub Projects

Lab 4 for **UTS 43030 Module 3 - GitHub Projects** (Lecture 4 practical activities, project case study).

A small Python task manager (`todo.py`) with unit tests (`todo-test.py`), packaged in Docker and run by
GitHub Actions. Every push to `main` rebuilds the container, runs the tests and regenerates
`index.html` (published with GitHub Pages). Merging a pull request that says `Closes #n` moves issue
`#n` to **Done** on the project board.

## Pipeline

```
feature branch ──push──► Pull request ("Closes #n")
                              │  ci.yml (pull_request): build image + run tests  → check on the PR
                              ▼
                         Merge PR ──► issue #n closed
                              │
           ┌──────────────────┴───────────────────────────┐
           ▼                                              ▼
 ci.yml (push to main)                         Project board → Status: Done
  docker build → docker run (repo mounted)       Recommended: built-in workflows
   ├─ todo.py        → ToDo / Done lists           ("Item closed", "Pull request merged")
   ├─ todo-test.py   → "test_x ... ok" report      Optional: tracker.yml (GraphQL + PAT)
   └─ update_index.sh→ rewrites <pre> blocks
  commit index.html → deploy to GitHub Pages
```

## Project structure

| Path | Purpose (course activity) |
|------|---------------------------|
| `README.md` | Documentation |
| `index.html` | Dashboard, regenerated by `update_index.sh` |
| `Dockerfile` | Containerises the scripts (Activity 7) |
| `.github/scripts/todo.py` | `Task` and `TaskPool` classes (Activity 3) |
| `.github/scripts/todo-test.py` | Unit tests with clean `... ok` output (Activity 4) |
| `.github/scripts/update_index.sh` | Writes tasks + test results into `index.html` (Activity 5) |
| `.github/scripts/entrypoint.sh` | Container entrypoint (Activity 6) |
| `.github/workflows/ci.yml` | CI/CD pipeline (Activity 8) |
| `.github/workflows/tracker.yml` | Moves linked issues to Done on PR merge (Activity 9) |
| `.github/pull_request_template.md` | Reminds you to write `Closes #n` |

## Run it locally

```bash
python3 .github/scripts/todo.py
python3 .github/scripts/todo-test.py
OUT_DIR=/tmp/tm bash .github/scripts/entrypoint.sh     # updates index.html in this folder
git restore index.html                                  # undo the local test

# With Docker Desktop (mirrors ci.yml):
docker build -t task-manager:latest .
docker run --rm -v "$PWD:/workspace" -w /workspace -e GITHUB_USER=me task-manager:latest
```
